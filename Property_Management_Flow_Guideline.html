Property Reservation

Trigger: Approved quotation + tenant ready to commit with deposit

flowchart TD A["Quotation Accepted by Tenant"] --> B["🏠 Create Property Reservation\nproperty.reservation"] B --> C["Issue Reservation Fee Invoice\nPHP 5,000 / 10,000 / Custom"] C --> D["Tenant Pays Reservation Deposit"] D --> E["Tenant Uploads Proof of Payment"] E --> F["Accounting Verifies Payment"] F --> G{Payment\nVerified?} G -- Yes --> H["Status: PAID & RESERVED\nUnit: occupancy_status = reserved"] G -- No --> I["Request Resubmission"] I --> E H --> J{Within Expiry\nDeadline?} J -- Yes --> K["▶ Phase 3: Lease Contract"] J -- Expired --> L["⚠️ Reservation Auto-Expires\nUnit released back to Available\nreservation_expiration_cron"] L --> M["Notify Tenant / Follow-Up"]
⚠️
Auto-Expiry: The reservation_expiration_cron runs daily and automatically expires unpaid or unconfirmed reservations past their deadline, releasing the unit back to Available status.

Trigger: Lease contract signed + financial clearance granted

flowchart TD A["Lease Contract SIGNED ✅"] --> B["🚪 Create Move-In Form\nmove.in.form"] B --> C["Link Lease Contract\nAuto-fills Tenant + Unit + Deposits"] C --> D["PMO Conducts Move-In Inspection\npmo.inspection"] D --> E["Document Unit Condition\nChecklist completed"] E --> F["Tenant Signature Captured\ndigital signature"] F --> G["Leasing Officer Submits Form"] G --> H{Contract in\nSigned Stage?} H -- Yes --> I["Grant Move-In Clearance\nstate: cleared"] H -- No --> J["🚫 Blocked: Contract Not Signed Yet"] I --> K["Confirm: MOVED IN ✅\nUnit = occupied\nLease = active"] K --> L["Register Pet\npet.registration"] K --> M["Issue Access Card/Biometrics\naccess.request"] K --> N["Setup Parking Slot\nparking.application"] K --> O["Setup Wi-Fi Account\nwifi.request"]
🚫
Business Rule (B3): Move-In Clearance is blocked if the linked Lease Contract has not reached at least signed_tenant stage. A tenant cannot move in without a signed lease.

Security Deposit Refund

Trigger: Move-Out Clearance fully signed off by all departments

flowchart TD A["Move-Out Clearance: ALL CLEARED ✅"] --> B["💵 Create Deposit Refund Record\nsecurity.deposit.refund"] B --> C["Link: Lease Contract +\nMove-Out Clearance"] C --> D["Populate All Deductions\nOutstanding Rent + Damage +\nUtility + Other Charges"] D --> E["Compute Net Refund\nDeposit − All Deductions"] E --> F{Net Amount?} F -- Positive --> G["Accounting Processes Refund\nIssue Check / Bank Transfer"] F -- Zero or Negative --> H["Deposit Fully Applied\nTenant may owe balance"] F -- Forfeited --> I["🔴 Deposit Forfeited\nBreach / Non-compliance"] G --> J["Accounting Approves Release"] J --> K["Management Final Approval"] K --> L["Refund RELEASED to Tenant ✅"] L --> M["Lease Contract → Closed/Terminated\nUnit → Available\n🏠 Cycle Complete"]
Refund Computation Formula
Net Refundable Amount =
    Original Security Deposit
    − Outstanding Rent Deduction
    − Damage & Repair Deduction
    − Utility Unbilled Deduction
    − Other Deductions
    = Net Refundable Amount (PHP)

Property Unit Status — State Machine

How a unit's occupancy_status changes throughout the tenant lifecycle

🟢
Available
Unit is vacant and can be leased. Shows on website.
🟡
Reserved
Reservation paid and verified. Unit is on hold — not available to others.
🔴
Occupied
Tenant has officially moved in. Active lease is running.
🔧
Under Repair
Post move-out repairs in progress. Not leaseable until cleared.
stateDiagram-v2 [*] --> Available : Unit registered in system Available --> Reserved : Reservation paid and verified Reserved --> Available : Reservation expired or cancelled Reserved --> Occupied : Lease active and tenant moved in Occupied --> Under_Repair : Tenant moves out + inspection done Occupied --> Available : Emergency release or breach Under_Repair --> Available : Repairs completed by PMO

Automated Cron Jobs

Background tasks that run automatically on schedule

💰

billing_cron_data — Monthly

Auto-generates billing records for all active leases on the configured due date (1st, 5th, 10th, 15th, or 30th of month).

Monthly
📋

lease_expiration_cron — Daily

Checks all active leases. Flags contracts within 90 days of expiry as "For Renewal Discussion" and sends alerts to leasing officers.

Daily
🏠

reservation_expiration_cron — Daily

Checks all pending reservations. Auto-expires records past their expiration date and releases the unit back to Available status.

Daily
